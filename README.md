이 저장소는 저를 소개하는 단일 페이지 포트폴리오 사이트의 소스 코드입니다.

## 디자인 시스템 — Ribbon & Pearl

콘셉트는 **"믿음을 주는 신뢰의 개발자"** 입니다. 빨간 새틴 리본처럼 한 번 묶은 약속은 풀리지 않게, 진주알을 꿰듯 꼼꼼하게.

### 색

| 역할 | 이름 | HEX |
| --- | --- | --- |
| 배경 | Pearl Ivory | `#FBF8F3` |
| 카드 · 섹션 | Surface Raised | `#F4EEE4` |
| 구분선 | Hairline | `#E3D9CB` |
| 본문 텍스트 | Walnut Ink | `#2A1E19` |
| 보조 텍스트 | Ink Muted | `#6B5D54` |
| 포인트 (CTA · 링크) | Ribbon Red | `#A3202C` |
| 보조 색 (태그 · 라벨) | Olive | `#5E5E3E` |
| 장식 전용 | Champagne Gold | `#B8955A` |

- 리본 레드는 한 화면에 한두 곳만 씁니다. 빨강이 많으면 경고처럼 보여 신뢰를 깎습니다.
- 골드는 대비가 낮아 텍스트에 쓰지 않고 가는 장식선에만 씁니다.
